# Smart Road Audio Guide Iceland (v2.0)

> **Інтелектуальний офлайн-автогід по Ісландії з підтримкою динамічного геотрекінгу, панорамних Vista-тригерів та попереджень безпеки SafeTravel.is.**

---

## 📌 Executive Summary
- **B2C Модель:** $30 за 7-денний «Iceland Explorer Pass» (безкоштовний тур по Рейк'явіку + 3 точки Золотого кільця).
- **B2B Модель:** 
  1. *Fleet Unlimited:* $1,000 – $3,500/рік на весь автопарк прокату (до 200 авто).
  2. *Metered Billing:* $0.80/активний день або $4.50/поїздка.
  3. *Partner RevShare (50/50):* $25 допродаж при бронюванні ($12.50 прокату / $12.50 нам).
- **Головна технологічна перевага:** 100% Offline-First (векторні карти MapLibre ~180 МБ + кешовані високоякісні аудіодоріжки).
- **Кілер-фіча безпеки:** Інтеграція сповіщень *SafeTravel.is* (голосові попередження про ураганні пориви вітру >25 м/с та заборону з'їзду на F-дороги для седанів).

## 📊 Верифіковані ринкові дані (Ferðamálastofa & Samgöngustofa)
- **Загальний потік туристів:** 2.3 – 2.5 млн / рік.
- **Частка Self-Drive:** 60% – 78% подорожують орендованими авто або кемперами.
- **Розмір флоту прокатів:** 25,000 – 33,200 зареєстрованих автопрокатних машин (*bílaleigubílar*).
- **Бенчмарк оренди GPS:** Прокати (*Blue Car Rental, Lotus*) здають старі навігатори Garmin за **1,700 ISK/добу (~$87.50 на тиждень)**. Наш додаток утричі дешевший і не потребує закупівлі заліза!
